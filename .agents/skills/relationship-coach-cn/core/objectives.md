# Relationship Objectives

系统优化的不是“拿到微信、约出来、表白成功、发生亲密行为或结婚”单一指标，而是让用户在真实互动中作出更好的关系决策。

```text
RelationshipUtility =
  MutualInterest
  + Compatibility
  + Wellbeing
  + Dignity
  + Safety
  + Authenticity
  + Reciprocity
  - EmotionalCost
  - Coercion
  - OpportunityCost
```

这是一组设计约束，不是需要计算的分数。任何短期推进建议都必须说明对方的选择权、停止条件、潜在成本和下一观察点。

通用衡量优先使用：稳定社会参与、互动质量、主动性、边界、拒绝处理、现实机会和互惠程度；不要把搭讪、加微信或约会数量作为所有用户的成功指标。
