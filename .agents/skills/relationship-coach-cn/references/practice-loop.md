# 从知识到现实互动的练习闭环

用途：用户希望加强恋爱能力、制定练习、复盘一次互动或继续上次咨询时按需读取。本文件是实践建议，不是心理测量、喜欢概率或效果保证。

## 先定位现实卡点

由用户确认当前最想改善的一项，不仅按日期、画像标签或练习分数推进阶段。

| 卡点 | 先练什么 | 对应课程 |
|---|---|---|
| 缺少机会 | 找自己愿意长期参加、公开且有共同任务的活动 | 1、2、7、33 |
| 想开口但迟迟不行动 | 共同情境、一点真实自我表达、自然收尾 | 4、6、9、11 |
| 聊天停在礼貌或追问 | 倾听感受、分享小故事、具体欣赏、温和幽默 | 5、10、11、25、35、36、82 |
| 有交流但约不出来 | 检查互惠，提出具体、可协商、容易拒绝的活动 | 13、14、38、44、48 |
| 不确定是否适合继续 | 同时观察自己的感受、双方投入和生活方向 | 15、17、22、50、58、59、85 |
| 等待或受挫时反复分析 | 区分事实与猜测，暂停冲动发送，恢复自己的生活 | 19、20、37、51、53、56 |

机会不足、活动不适合、时间不足、双方不合适，与表达或情绪困难是不同问题。没有恋爱对象不直接归因为执行失败；入学自检只提供建议，用户可以改选。

## 一轮只练一个动作

1. 用一个当前阶段的虚构情境，让用户先自己回应。
2. 反馈一个已经做到的具体点和最多三个可改进点；不先给可背诵的标准答案。
3. 用户重练一次，比较表达变化；重写得更好不改变已发生的对方回应。
4. 用户愿意且情境适合时，把一个小动作带到真实互动。没有机会时，与愿意陪练的朋友练习或先完成活动准备，不为完成任务强行接近某个人。
5. 下次只收集去标识化、完成判断必需的信息，再调整下一步。

## 现实复盘至少分开六件事

- 原观察目标：想验证双向投入、改善表达，还是照顾自己的生活？
- 是否尝试：实际尝试、还没尝试、没有合适机会。
- 可观察事实：对方实际说了什么、是否主动参与安排、约定是否兑现。用户先去除可识别信息，不要求上传原始聊天。
- 自己的表现与体验：是否表达真实想法、是否自在、是否恢复自己的安排。
- 双方的意愿与边界：礼貌不等于恋爱意愿；相处愉快不等于同意亲密行为；自己的不舒服和退出意愿同样有效。
- 新的判断：哪些解释被支持，哪些仍未知，下一次只调整什么，以及何时停止。

未尝试、没有回应或证据不足，结果保持 `unknown`。只观察到边界受到尊重，不能推断自己的生活已经恢复；只观察到表达更清楚，不能推断对方更喜欢自己。明确拒绝、发现不合适或体面结束，也可以是有效结果。

将每次互动作为独立事件；同日同一卡点不覆盖此前事件。后来获得可观察信息时，可明确补充原记录并保留先前版本；未知补充不能抹掉已知观察。同一次互动已经出现的拒绝或越界，不由后来的一般友好回应取消。另一段明确、自愿的新互动另行记录，不能把旧记录的停止条件当作跨对象的永久锁定。

根据本次证据选择下一轮准备方向；停止后的建议优先恢复自己的生活，不要求再次联系已拒绝的对象。用户可改选方向。对应课链接直接打开原文，阅读动作本身不证明掌握或现实迁移。

## 连续约会的六段练习

初识 → 见面相处 → 约会后联系 → 再次邀约 → 表达好感 → 关系协商。

每一段提供明确互惠、证据模糊、明确拒绝、双方不合适的分支。仅在该情境出现直接表达或具体互惠安排后探索下一段；不按见面次数强行升级。模糊时保留阶段并给空间，持续单向或模糊时降低投入；拒绝或不合适时停止该次推进。重练只调整自己的表达，不覆盖已经观察到的结果。

本地产品提供看展、兴趣运动、朋友聚会三组情境。编辑草稿后必须重新检查；旧反馈不能确认推进。历史显示实际选中的模拟回应，用户自行结束不编造对方拒绝。重练比较具体表达变化，不给出喜欢概率或关系升级评分。

正向相处需要同时练习真实兴趣、生活故事、具体欣赏、自然幽默、回应情绪和共同体验。幽默不以对方的弱点为笑料，不用嫉妒、消失、羞辱或制造焦虑换取回应。身体接触需要清楚、具体、清醒、可撤回的同意，模糊回应不能作为同意。

产品最多保留30个匿名现实事件，各含最多5个此前版本；全部可展开、补充。主对话重置保留独立复盘与保存设置，并清理模拟草稿；恢复备份会失效旧会话的待处理分析，防止其覆盖恢复后的记忆同意设置。

练习评分只描述本地规则符合度；稳定答题、软件测试通过和完成模拟，都不能替代现实关系效果验证。
