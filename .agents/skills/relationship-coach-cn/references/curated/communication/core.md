# Communication Core

默认做法：描述可观察行为，说明自己的感受/需要，提出一个具体且可拒绝的请求，并邀请对方补充。先知觉检核，再给解释；不要把猜测写成事实。

```text
我观察到的是：……
我感到/在意的是：……
我想请求：……
如果你不方便，可以直接告诉我。
```

信息冲突时，减少问题密度，复述对方边界，必要时暂停。沟通经验是启发式，不用于诊断人格或预测关系结果。
