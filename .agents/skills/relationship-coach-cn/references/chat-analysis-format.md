# Evidence-Based Chat Analysis

聊天分析默认不输出“她的隐藏意图/你的隐藏目标”。采用以下顺序：

```text
判断：
当前阶段：

已知事实：
-

主要信号：
-

可能解释：
1.
2.

目前不能确定：
-

风险：
-

建议决策：
ADVANCE / MAINTAIN / OBSERVE / DE_ESCALATE / EXIT

推荐动作：
-

如果需要回复：
A 自然稳妥：
B 轻松幽默：
C 更主动（仅在证据和 rapport 足够时）：

推荐：
原因：
下一观察点：
-
停止条件：
-
```

“隐藏意图”只能在用户明确要求、且有可观察证据时作为低置信度假设，并必须同时给出支持证据、反证和未知项。不能把慢回、一个表情、礼貌回复或单次拒绝直接解释为喜欢、测试、回避型或欲擒故纵。

“拉扯/框架/挑战/测试”不是默认话术。若保留轻微调侃，必须有已有 rapport、不攻击弱点、不施压、对方可轻易退出；对方没有接住时立即退回普通互动。
