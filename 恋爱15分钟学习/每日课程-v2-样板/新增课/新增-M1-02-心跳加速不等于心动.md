# 新增课 M1-02：心跳加速不等于心动——唤醒是怎么被误读的

> 季：S1 进入关系 ｜ 模块：3 邀约与初约（建议插入第 14 课之后）｜ 机制层：M1 吸引与选择
> 证据：`[E]`×1 `[T]`×1 `[U]`×1 ｜ 门控：待评分

## 今天的目标

分清"和这个人在一起我安心"与"和这个场景我兴奋"——只做诊断，不做设计。

## 2 分钟机制：身体先有反应，大脑后找原因

有一个经典实验：让男性被试走过一座摇晃的吊桥，或者一座稳固的桥，然后在桥尾由同一位女性访谈员留下联系方式。结果走吊桥的那组，事后主动联系的比例明显更高，对访谈员的吸引力评分也更高。

解释是：**心跳加速、手心出汗这些生理反应，本来没有标签**。大脑要给它一个原因，而在那个当下最容易抓到的原因，就是眼前的人。于是"我紧张"被读成了"我心动了"。

这在心理学里叫**唤醒的错误归因**：生理唤醒的来源会被错误地分配到身边的人身上。

这条机制有三层用法，只有前两层是安全的：

1. **诊断**：我现在的"心动"，有多少来自这个人，多少来自这个场景（第一次约会、酒精、竞技、恐怖片、深夜）？
2. **解释**：为什么"一起做过刺激的事"会让人觉得更亲近——因为它确实提高了唤醒水平。
3. **设计**：**不能做**。刻意安排刺激场景、制造竞争感、让对方处在不安里以提高对你的感觉，这不是吸引力，这是操纵。它损害的是知情选择。

`[E]` 吊桥实验（Dutton & Aron, 1974）｜`[U]` 该实验的现场效应在后续重复研究中大小不一，实验室版的错误归因效应较稳定，真实约会场景的效应量存疑｜`[T]` 唤醒的标签化解释（Schachter 的双因素理论）

## 2 分钟核心概念

区分两个词：

- **唤醒**：身体被激活。紧张、兴奋、害怕、运动后，都是同一种生理底色。
- **安心**：身体放松且有依靠感。它的表现是呼吸变慢、肩膀放下、不需要表演。

两者都可能是喜欢的成分，但**它们指向不同的关系**：高唤醒容易产生"强烈"，安心容易产生"长久"。把强烈当成唯一指标的人，会在关系变平静后误判"没感觉了"——这正是很多人在第 3 个月退出的原因。

## 4 分钟场景：两个版本

**版本 A（常见做法）**

第一次约会你选了一家很吵的livehouse，全程靠喊话。回家后你心跳很快，反复回想，判断"就是她了"。第二次约在安静的咖啡馆，你发现你们聊不到 20 分钟。

**差在哪**：第一次的强烈体验，主要来自环境音量、酒精和新鲜感。你没有做错什么——错的是把"场景的强度"记成了"关系的强度"。

**版本 B（更好做法）**

同样两次约会，你在第二次之后这样记录：

> 第一次：livehouse，很吵，聊得少，但很兴奋。
> 第二次：咖啡馆，安静，聊了两小时，中间有三次沉默，不尴尬。
> **哪一次我更放松？第二次。哪一次我更想再去？都想去——但原因不一样。**

然后做第三次，选一个**中性场景**（散步、超市、做饭），看哪种感觉还在。**中性场景是唯一能过滤掉场景噪音的测试。**

## 3 分钟练习

回想最近三次和同一个人的互动，填三列：

| 场景（刺激/中性/安静） | 当时的身体状态（心跳、紧张、放松） | 事后 24 小时里我想起她的次数 |
|---|---|---|
| | | |
| | | |

**看规律**：如果"想起的次数"只在刺激场景后飙升，那你可能迷上的是唤醒，不是人。
**再看一列**：哪一次你**没有表演**？不需要表演的那次，信息量最大。

## 2 分钟现实行动

下一次约会，选一个**中性、有点无聊、需要合作**的场景（买菜做饭、逛超市、坐公交去一个远地方）。什么都不用做，只观察一件事：**无聊的时候，你们还能不能待在一起。**

## 2 分钟复盘与停止条件

**停止条件**：
- 你开始**故意**制造紧张（临时改计划、提及其他追求者、忽冷忽热）来"提高她的感觉" → 立刻停。这是操控，不是吸引。
- 你把"我很紧张"直接等同于"我很喜欢" → 停，先做上面的三列记录。
- 关系变平静后你判断"没感觉了" → 先检查是不是把"平静"误读成"不爱"。平静是长期关系的常态，不是失败信号。

## 依据

- `[E]` 唤醒的错误归因：吊桥实验（Dutton & Aron, 1974）。
- `[T]` 双因素情绪理论：生理唤醒 + 认知标签共同构成情绪体验（Schachter & Singer, 1962）。
- `[U]` 吊桥实验的重复性与现场效应量存在争议；实验室条件下的错误归因较稳定，真实约会场景不宜当作规律使用。
- `[C]` 本课综合："中性场景测试"是把该机制转译为可执行的自检，不是原研究做法。
