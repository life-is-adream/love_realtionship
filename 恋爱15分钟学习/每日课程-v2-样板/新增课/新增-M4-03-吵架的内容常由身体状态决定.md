## 今天的目标

在下一次冲突里，先记录**身体条件**，再判断**议题**。

## 2 分钟机制：压力会漏进关系里，睡眠会直接改变一场吵架

有两个常被忽略的变量，对冲突的影响比"沟通技巧"更直接。

**第一个是压力的渗漏。** 工作里被压了一天的人，回家后对同一句话的反应会更强。研究里把这种现象叫**压力渗漏**：外部压力不会停在门口，它会改变你在家里的耐心阈值、解读方式和回应速度。而且它常常不是以"我今天很累"的形式出现，是以"你怎么又没关灯"的形式出现。

**第二个是睡眠。** 有研究让伴侣连续记录睡眠与冲突，结果显示：**前一晚睡眠质量差，第二天的冲突更多、更难解决**，而且共情能力下降——不是不愿意理解对方，是当下调不出那个能力。

这两条合起来给出一个很实用的推论：

> **很多"我们沟通有问题"，其实是"我们都在低电量状态下沟通"。**

还有一条更朴素的：**饿、累、疼、醉的时候，人没有能力做复杂对话。** 这不是修养，是资源问题。

## 2 分钟核心概念

冲突前先做一次"状态检查"，四个变量，三十秒：

| 变量 | 问题 | 如果答案是"差" |
|---|---|---|
| 睡眠 | 昨晚睡够了吗 | 不发起重要对话 |
| 进食 | 上一次吃东西是几小时前 | 先吃，再谈 |
| 压力 | 今天有没有被什么压着 | 先说"我今天很差"，再谈事 |
| 物质 | 喝了多少酒 | 不谈。醉的时候不谈任何重要的事 |

**注意**：这不是给坏脾气找借口。状态差解释的是**为什么今天特别容易炸**，不是**炸了就可以不算**。责任照旧，只是可以选择**不在最差的时候处理**。

## 4 分钟场景：两个版本

**版本 A（常见做法）**

晚上 11 点半，两个人都累了一天。她提了一句"下个月房贷怎么安排"，你回了一句"现在说这个？"——三分钟后你们在吵"你到底关不关心这个家"。

**差在哪**：议题是房贷，但真正的变量是**时间（23:30）+ 睡眠债 + 空腹 + 各自的压力**。你们在最差的条件下谈最需要计算能力的事，谈崩是必然的，只是崩的形式随机。

**版本 B（更好做法）**

同样的 11 点半，你说：

> "这个事得谈，而且得认真谈。我现在脑子是浆糊，谈出来肯定是吵架。
> 明天上午十点，我们带电脑坐下来算，半小时。今晚先睡。"

第二天上午，同样的议题，同样两个人，结论往往完全不同。

**差在哪**：版本 B 没有回避议题，它做了**排期**——把"要不要谈"换成了"什么时候谈"。它承认了一个事实：**议题的难度不变，但你的处理能力随时段变化。**

## 3 分钟练习

接下来一周，每次冲突后记三列（不超过 30 秒）：

| 时间 | 昨晚睡了几个小时 / 上次吃饭是几小时前 | 这场吵的是什么 |
|---|---|---|
| | | |
| | | |

**看规律**：如果冲突集中在某个时段（晚上 10 点后、周一、发薪日前），那不是"我们问题多"，是**你们总在最差的时候开会**。

**自检问题**：这一周有没有一次冲突，是在"状态好"的时候发生的？如果一次都没有，那你要修的可能不是沟通，是作息。

## 2 分钟现实行动

今天定一条规则，写下来贴在冰箱或发在两个人的聊天里：

> `重要的事不在 22:30 之后谈；不在饿的时候谈；不在喝酒之后谈。`

一句话就够。规则的作用不是禁止冲突，是**把冲突挪到你们打得赢的场地**。

## 2 分钟复盘与停止条件

**停止条件**：
- 你用"我太累了"来为伤人的话免责 → 停。状态解释原因，不抵消后果。该道歉还是要道歉。
- "状态不好"变成长期不谈事的理由（连续两周所有议题都被推迟）→ 这不是排期，是回避。
- 对方在酒后、疲惫时反复出现推搡、辱骂、砸东西 → 这已经超出本课范围，去第 133 课（暴力与控制），安全优先。
