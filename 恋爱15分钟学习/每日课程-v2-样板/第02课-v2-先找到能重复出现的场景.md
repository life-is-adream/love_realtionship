# 第 02 课（v2）：先找到能重复出现的场景

> 阶段：二 认识人 ｜ 机制层：M1 吸引与选择 ｜ 证据：`[E]`×2 `[C]`×1

原课日期 2026-07-18

## 今天的目标

选**一个**公开、稳定、有共同任务的活动，并连续去四周。

## 2 分钟机制：为什么"重复出现"本身就有用

人对一个人产生好感，有一部分不来自他做了什么，而来自**他出现了几次**。

1968 年，扎荣茨做过一个很朴素的实验：让人反复看一些无意义的符号和面孔，再混入一批没见过的。结果是——看过的那些被评价为"更喜欢"，即使当事人说不出理由。这叫**曝光效应**：熟悉本身会产生好感，不需要对方做任何特别的事。

后一环更关键。1950 年代对西点公寓的研究发现，住户的友谊高度集中在**门口、楼梯、信箱附近**——不是因为那些人更讨人喜欢，而是因为**撞见他们的次数更多**。研究者把这种距离叫"功能性距离"：不是地图上的远近，是**你们一天里会碰见几次**。

两件事合起来，给出一条可操作的推论：

> 选场景时，别问"这里的人怎么样"，问"我会不会一周碰见同一批人三次"。

`[E]` 曝光效应（Zajonc, 1968）；功能性距离预测友谊形成（Festinger, Schachter & Back, 1950）

## 2 分钟核心概念

一次性随机开场的问题不在"话术不够好"，而在**它把一次判断压在了 30 秒里**——你要在零信息下让人决定愿不愿意继续，对方也一样。

可重复的场景反过来做：先有共同任务，再有几次低风险的短交流，判断被摊开在两周里。你不需要第一句话就很精彩，你只需要**存在得足够自然**。

优先顺序：学校组织、运动队、读书会、志愿服务、固定讲座、朋友的小聚会。
避开：一次性活动、需要走很远才能"偶遇"的地方、封闭或夜间场所。

## 4 分钟场景：两个版本

**版本 A（常见做法）**

你在一次性的行业沙龙上，看见一个人站在旁边，走过去说："你好，我觉得你挺有意思的，能加个微信吗？"
对方笑了一下："可以啊。"——加了。回去发消息，三天没有回应，你开始反复琢磨那句"可以啊"是什么意思。

问题不在被拒绝，在于：**这次互动没有第二次见面的理由**。加了微信也不构成关系入口，只构成一个孤立的联系方式。

**版本 B（更好做法）**

你报了一个每周三晚上的羽毛球活动，第二次去时和同组的人说：

> "你也是固定周三来吗？我上个月才开始打，还在找能坚持的场次。"

对方如果只回"嗯，偶尔"，你就回到练习里，不再追问。
对方如果说"我基本每周都来"，你可以接：

> "那下次缺人的时候可以叫我，我一般都在。"

**差在哪**：版本 B 里，"加微信"不是目标，是**为下一次见面留一个自然的接口**。你不需要对方当场产生好感，只需要让"再见到"这件事变得正常。

**一个自检**：如果这次互动结束后，你们没有任何理由在同一个空间里再出现——那就不是入口，是一次性接触。

## 3 分钟练习

列出三个你**愿意连续参加四周**的活动，每个填四栏：

| 活动 | 共同任务是什么 | 一周会碰到同一批人几次 | 我不舒服时可以怎么退出 |
|---|---|---|---|
| | | | |
| | | | |
| | | | |

填完问自己：**"如果四周里我一句话都没和新人说，我还愿意去吗？"**
答案是"不愿意"，说明你选的是"认识人的工具"，不是"你想做的事"——这类活动通常坚持不过第三周。

## 2 分钟现实行动

今天只做一件事：在三个活动里选**一个**，完成报名、问清时间，或约一个朋友同去。

不设"必须认识人"的子目标。这一课的唯一指标是：**下周三你还会出现在那里。**

## 2 分钟复盘与停止条件

复盘问一句：我是真的想去这个活动，还是只想借它认识人？

**停止条件**（出现任一条就停）：
- 对方回应持续在三个字以内且不反问 → 回到活动本身，不再开启新话题。
- 对方在封闭空间、夜间、或明显赶时间时 → 不发起邀请。
- 你开始计算"他今天看了我几次" → 停。这是把曝光效应用成了监控。
