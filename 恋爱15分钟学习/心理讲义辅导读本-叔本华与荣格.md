## 0. 先读这一页：这本读本是什么，不是什么

| 是 | 不是 |
|---|---|
| 课程之外的「辅导层」：把课程里的机制，接上两位思想家的问题 | 原著的替代品；不鼓励用二手转述代替读原书 |
| 一组可验证的自问：我观察到什么？我补出了什么？下一步做什么？ | 一套关于对方的结论；不预测、不诊断、不贴类型标签 |
| 对两位作者的**选择性使用**：只用与亲密关系相关、且能与现实经验对照的部分 | 对两位作者的全面介绍；形而上学、宗教、炼金术不在本读本范围 |
| 一份带证据边界的阅读材料 | 临床心理学或精神医学建议；不处理危机、暴力与精神健康问题 |

### 三条使用规则

1. **先上课，再读本。** 读本是辅导，不替代课程里的动作、边界和停止条件。
2. **每节只带走一个可验证的问题。** 不带走一个关于「他/她是什么人」的结论。
3. **两位作者都不是关系科学家。** 他们的价值在提出好问题，不在提供证据。凡是把他们的思辨当规律用的地方，本读本都会标出来。

### 证据标注

沿用课程的四级标注，并额外加一句「思辨提示」：

| 标注 | 含义 | 在本读本里的用法 |
|---|---|---|
| `[E]` | 有可查研究或元分析，方向较稳定 | 只用于能被独立研究检验的说法 |
| `[T]` | 成熟理论框架，证据混合或依赖情境 | 包括哲学与分析心理学的思辨框架 |
| `[C]` | 课程综合、临床经验、常识推断 | 明确写成「本读本综合」 |
| `[U]` | 流行但证据不稳，或存在明显争议 | 必须写清争议在哪，不删不藏 |

> **思辨提示**：叔本华的「意志」与荣格的「原型」都属于`[T]`，且**不可直接实证检验**。它们可以帮助你换一个角度提问，但不能用来证明「对方就是这样」「我们注定如此」。

## 2. 叔本华 I：欲望的钟摆

### 2.1 一句话机制

**欲求来自匮乏；满足是短暂的；于是人会在「痛苦」与「无聊」之间来回摆动。**

### 2.2 原著在说什么（意译概述）

叔本华在《作为意志和表象的世界》里提出：我们经验到的世界，一面是「表象」（我们如何看它），另一面是「意志」（一股盲目的、不断求存的冲动）。**这里的「意志」不是「意志力」**，而是一股非理性的、没有明确目标的求存冲动。人的欲望是这股意志在个体身上的显现。欲望来自「缺」；缺就痛；一旦满足，痛苦暂时消失，但满足本身并不带来持续的幸福，很快又滑向无聊，然后再产生新的欲望。

他还提出一个常被误读的推论：**满足是消极的**——我们更能感受到「不再痛」，而不是「很幸福」。所以人容易把「得到」当成终点，但得到之后，目标立刻移动。

### 2.3 放进恋爱里

| 阶段 | 钟摆位置 | 常见误读 | 课程里的做法 |
|---|---|---|---|
| 追不到 | 痛苦 | 「只要得到她/他，我就幸福了」 | 接受拒绝，回到生活与社交 |
| 刚在一起 | 短暂满足 | 「我们会一直这样」 | 享受当下，但不做永久承诺 |
| 稳定期 | 无聊 | 「没感觉了，就是不爱了」 | 建立共同任务、共同意义与仪式 |
| 又遇到新人 | 新的欲望 | 「这才是真爱」 | 先分清是「新鲜感」还是「适配度」 |

关键区分：

- **欲望 ≠ 需要。** 需要是「我需要稳定的回应、尊重、边界」；欲望是「我现在想要那种心跳」。需要可以协商，欲望会移动。
- **强度 ≠ 适配。** 心跳很响，只能说明唤醒高，不能说明你们合适。
- **得到 ≠ 拥有。** 得到一个人，不等于拥有关系；关系需要持续投入和协商。

### 2.4 可验证练习：欲望三栏表

写下你最近最强烈的一个「我想要」：

| 我想要 | 得到之后的第 30 天，具体会是什么样 | 如果永远得不到，我还能怎么活 |
|---|---|---|
| | | |

**自检问题**：

- 第二栏如果你写不出具体画面，说明你想要的可能不是这段关系，而是「摆脱现在的状态」。
- 第三栏如果你写不出任何东西，说明你把全部自我价值押在了这一个结果上。

### 2.5 停止条件

- 你开始用「得不到的才珍贵」解释一段**不健康**的关系 → 停。这是把伤害浪漫化。
- 你把对方当成「止痒工具」，只在孤独时联系 → 停。这不是关系，是消耗。
- 你反复用「换一个人」来解决无聊 → 停。先检查共同任务与自我结构。

### 2.6 证据与边界

- `[T]` 意志、欲求与满足的短暂性（叔本华，《作为意志和表象的世界》，1818/1844）。**哲学思辨，不是实证结论。**
- `[E]` 享乐适应：强烈的正向事件带来的幸福感会逐渐回归基线（Frederick & Loewenstein, 1999，综述）。
- `[U]`「爱情必然从痛苦走向无聊」是悲观主义推断，不是关系规律。现实中有大量关系在激情下降后仍然高满意。
- `[U]` 叔本华《论女人》等文本带有明显的时代偏见与性别本质化，**不作为关系建议使用**，只作批判性阅读。

**本节只留一个问题**：我现在想要的，是这个人，还是「不再痛苦」的感觉？

## 3. 叔本华 II：爱情是「物种的计谋」吗

### 3.1 原著在说什么（意译概述）

在《论爱情的形而上学》里，叔本华提出一个大胆的思辨：个体以为自己是在追求个人的幸福，实际上，是「物种的意志」借个体来选择更有利于后代的对象。于是恋爱中的激情像一种暂时的幻觉；当物种的目的（结合与繁衍）完成后，激情就会退去，个体才发现自己选的可能并不适合长期相处。

### 3.2 可以用的部分

- 强烈心动里，确实可能包含**生物性偏好**、**新奇感**和**投射**，不全是「灵魂契合」。
- **不要用心动强度来预测关系质量。** 这是本节能给课程的最实用一条。
- 激情平均会回落。回落本身不是失败，关键看回落之后还剩什么。

### 3.3 不能当结论的部分

- 「物种意志」是一个**目的论式的哲学假设**，不可检验。它不能证明「你选她/他是因为基因」。
- 它也不是进化心理学。进化心理学有具体的可检验假设，叔本华没有。
- 他的性别观把女性当作物种繁衍的工具，这是**时代偏见**，不是描述。

### 3.4 可验证练习：心动拆解表

| 项目 | 你的记录 |
|---|---|
| 心动强度（0–10） | |
| 我**观察到**的证据（原话、行动、持续回应） | |
| 我**补出来**的故事（「她/他一定觉得我……」） | |
| 对方给过的**真实反馈**（接受/拒绝/含糊） | |
| 三个月后，可能还剩下什么 | |

**自检问题**：如果去掉「心跳」和「她/他很特别」这两句，你还剩几条能说清楚的理由？

### 3.5 停止条件

- 你用「基因注定」「物种选择」来解释对方的冷淡或自己的越界 → 停。这是给行为找借口。
- 你用「物种意志」为外貌、年龄、性别的刻板偏好背书 → 停。群体统计不能替代个人选择。
- 你把「激情退了」直接等同于「关系完了」→ 停。先看有没有共同意义、修复能力和日常善意。

### 3.6 证据与边界

- `[T]`「物种意志」与爱情的幻觉（叔本华，《附录与补遗》，1851）。**思辨，不可实证。**
- `[E]` 吸引力受相似性、邻近、熟悉、唤醒等因素影响（课程 M1 已引；Montoya, Horton & Kirchner, 2008；Feingold, 1988）。
- `[E]` 婚姻满意度平均随时间下降，但个体差异很大（Karney & Bradbury, 1995，纵向研究综述）。
- `[U]`「男人/女人本质上如何」这类结论，在叔本华那里是偏见，在现代研究里也常被过度推广。

**本节只留一个问题**：除了心动，我还能列出哪三条**可观察**的适配证据？

## 4. 叔本华 III：同情、痛苦与边界

### 4.1 原著在说什么（意译概述）

叔本华在《伦理学的两个基本问题》里把「同情」（Mitleid）当作道德的根基：真正有道德的行为，不是因为计算回报，而是因为看见他人的痛苦，并把这种痛苦当作真实的、值得回应的。他还用「个体化原理」来说明：我们平时把「我」和「你」分得很清楚，但同情让人短暂地穿透这层界限。

### 4.2 放进恋爱里

共情是关系里最重要的能力之一，但**共情不等于替对方承担**。叔本华的同情容易被误用成两种东西：

- **拯救者情结**：「他/她这么痛苦，只有我能救。」
- **无边界的付出**：「我心疼他/她，所以我不能拒绝。」

课程要加的一条是：**同情是看见，不是接管。** 你可以承认对方的痛苦是真的，同时不接下不属于你的责任。

### 4.3 可验证练习：「我心疼他/她」三问

| 问题 | 你的回答 |
|---|---|
| 这是**他/她**的痛苦，还是**我**的责任？ | |
| 我能做的**一件具体事**是什么？（限时、限量） | |
| 我**不做什么**？（写一条边界） | |

例句：

> 「我听见你很难受，我也愿意陪你一会儿。我能做的是今晚听你说 20 分钟；但我不能替你解决你和家人的事，也不能因为你需要我，就取消我明天的手术。」

### 4.4 停止条件

- 你以「我同情他/她」为由，持续忍受辱骂、控制、经济剥削或性压力 → 停。同情不是留下受伤害的理由。
- 你把「拯救」当成爱，只在他/她崩溃时才有连接 → 停。这是角色，不是关系。
- 你只给情绪安慰，不给具体行动，也不设时限 → 停。共情会变成耗竭。

### 4.5 证据与边界

- `[T]` 同情作为道德基础（叔本华，《伦理学的两个基本问题》，1841）。**哲学伦理框架，不是临床指南。**
- `[E]` 共情与亲社会行为存在稳定关联，但共情也会受偏见与疲劳影响（Batson 等，1990 年代一系列实验）。
- `[C]`「同情 + 边界」的组合，是本读本结合课程与临床常识的综合，不宣称是叔本华原意。
- `[U]` 把「同情」当作唯一道德标准，会忽略正义、同意与责任分配。

**本节只留一个问题**：我是在看见他/她的痛苦，还是在接管他/她的人生？

## 5. 叔本华 IV：无聊、日常与长期关系

### 5.1 原著在说什么（意译概述）

叔本华有一个著名的比喻：人生像钟摆，在痛苦与无聊之间摆动。欲望未满足时痛苦，满足后短暂，随后无聊，再产生新的欲望。他还认为，绝大多数人的一生都在为这两种状态寻找出口。

这个判断是悲观的，但它有一个可用的部分：**长期关系不能靠持续激情维持。** 激情是事件，日常是结构。

### 5.2 放进长期关系里

- 激情下降是**平均趋势**，不是道德失败，也不是「不爱了」的证据。
- 长期关系更稳的支撑，是共同任务、共同意义、日常善意和修复能力。
- 「无聊」是一个信号：要么关系里缺少新任务，要么个人生活里缺少支点。

### 5.3 可验证练习：抗无聊清单

| 类型 | 写一条具体的 |
|---|---|
| 每周一个新共同任务（做饭、徒步、看展、一起学一项技能） | |
| 三个可重复的共同兴趣（不依赖消费） | |
| 一个只属于两人的仪式（每周固定的一次散步/一顿饭） | |
| 一个关系外的个人支点（朋友、运动、创作、学习） | |

**自检问题**：过去一个月，你们一起做过哪件事，是**两个人都能说出细节**的？如果说不出来，问题不是「没感觉」，是「没有共同经历」。

### 5.4 停止条件

- 你把「无聊」直接解释为「不爱了」，并以此启动分手或出轨 → 停。先检查结构，再做决定。
- 你用第三者、暧昧或冷热游戏来解决无聊 → 停。这是把成本转嫁给别人。
- 你要求对方「永远让你兴奋」→ 停。这是把伴侣当娱乐产品。

### 5.5 证据与边界

- `[T]` 痛苦与无聊的钟摆（叔本华，《作为意志和表象的世界》）。**哲学隐喻，不是心理学定律。**
- `[E]` 婚姻满意度平均随关系时长下降，但下降幅度与个体、情境高度相关（Karney & Bradbury, 1995）。
- `[C]` 共同意义、日常善意与修复尝试，是 Gottman 研究里反复出现的长期关系特征（课程已引《幸福的婚姻》）。
- `[U]`「七年之痒」是流行说法，具体年限缺乏稳定证据；不要用它预测自己的关系。

**本节只留一个问题**：我们最近一次「两个人都能说出细节」的共同经历，是什么时候？

## 6. 荣格 I：投射——你爱上的，有多少是你自己

### 6.1 原著在说什么（意译概述）

荣格认为，人会把无意识里的内容「投射」到外部对象上。最典型的是「阿尼玛/阿尼姆斯」：每个人心里有一个关于「理想异性」的内在图像，遇到接近这个图像的人，就容易产生强烈的吸引。你以为是「她/他太特别了」，其中有一部分，是你把自己的内在图像放了上去。

荣格还有一句流传极广的转述：**未被意识到的东西，会以命运的形式出现。**（这句常见版本未必是荣格原文，本书只取其朴素含义。）它常被简化成鸡汤，但有一个可用的版本：你没看清自己的模式，就会反复遇到同一类人、同一类结局。

### 6.2 放进恋爱里

心动 = **对方的真实特质** + **你的内在图像** + **当下的唤醒**。三者混在一起，所以你很难分清「我喜欢的是她/他，还是我喜欢的是我对她/他的想象」。

失望往往不是「她/他变了」，而是**投射撤回了**：图像碎了，真人露出来了。所谓「下头」，有时是真实信息终于盖过了想象。

关键不是否认心动，而是**分离**：

- 哪些是我看到的？
- 哪些是我补出来的？
- 哪些是我需要直接问的？

### 6.3 可验证练习：看到 / 补出 / 核对

选一个你正在心动的人：

| 我看到的（可观察） | 我补出来的（故事） | 我需要核对的一个问题 |
|---|---|---|
| 她/他记得我说过的事 | 「她/他一定很喜欢我」 | 「你昨天记得我不吃香菜，是特意问的吗？」 |
| 她/他回消息慢 | 「她/他不在乎我」 | 「你最近消息少，是忙，还是需要空间？」 |
| 她/他对我笑 | 「她/他对我有意思」 | 「你上次说下次一起吃饭，是客气还是真的？」 |

**自检问题**：三栏里，哪一栏最长？如果「补出来的」最长，说明你在用想象推进关系。

### 6.4 停止条件

- 你用「你只是投射」来否定对方的真实感受与诉求 → 停。投射不是万能解释，更不是堵嘴工具。
- 你在**三次真实互动之前**就用「不是我理想型」淘汰对方 → 停。你淘汰的可能是想象，不是人。
- 你试图把对方改造成你的内在图像 → 停。这是控制，不是爱。

### 6.5 证据与边界

- `[T]` 投射、阿尼玛/阿尼姆斯（荣格，《Two Essays on Analytical Psychology》，CW7；《心理类型》，1921）。**分析心理学框架，不可直接实证。**
- `[E]` 积极错觉/理想化与关系满意存在关联（Murray, Holmes & Griffin, 1996）。注意：理想化有时有益，有时会掩盖问题。
- `[U]` 原型层面的「投射」没有标准化测量；「投射」一词在网络上常被滥用为指责。
- `[C]`「看到 / 补出 / 核对」三栏，是本读本把荣格概念转成可操作练习的综合写法。

**本节只留一个问题**：我对她/他的这个判断，哪一半有原话或行动作证？

## 7. 荣格 II：阴影——你最受不了的，可能也是你不敢承认的

### 7.1 原著在说什么（意译概述）

荣格用「阴影」指那些被自我否认、压抑或不愿承认的部分。阴影不一定是「坏」的：它也可能包含被压抑的野心、愤怒、性欲、脆弱，甚至才华。阴影通常不会安静地待着，它会在**你对别人的强烈情绪**里露头：你最受不了的那一点，常常与你不敢承认的那一部分有关。

### 7.2 放进恋爱里

- 你被「坏情人」强烈吸引，可能不只是判断失误，也可能是阴影在借他/她表达你没允许自己有的部分。
- 你对伴侣某个小动作异常愤怒，可能因为它踩到了你不允许自己有的特质。
- 但要注意：**阴影不是免责声明。** 对方打人、撒谎、控制、出轨，不是「你的阴影问题」，是他/她的行为问题。

### 7.3 可验证练习：三条「受不了—我也有」

| 我最受不了伴侣的三点 | 我是否也有一点（0–10） | 如果有一点，它在我生活里怎么出现 |
|---|---|---|
| | | |
| | | |
| | | |

**自检问题**：这张表的目的不是让你自责，而是让你把「他/她怎么这样」换成「我为什么对这一点反应这么大」。如果某一项你打了 0，也请写一句「我确定的原因是什么」。

### 7.4 停止条件

- 你用「你有阴影」来解释对方的暴力、控制或撒谎 → 停。这是把加害责任转移给受害者。
- 你用「我在整合阴影」为出轨、暴怒、羞辱开脱 → 停。整合是看见，不是放纵。
- 你用「你在投射」堵住对方的具体诉求 → 停。先回应行为，再谈理论。

### 7.5 证据与边界

- `[T]` 阴影与个体化（荣格，《Aion》，CW9ii；《原型与集体无意识》，CW9i）。**分析心理学框架，不可直接实证。**
- `[U]` 阴影没有标准化测量；「你只是把阴影投射给我」这类说法，在冲突中极易变成指责。
- `[C]` 把阴影转成「强烈情绪—自我检查」的练习，是本读本的综合，不是荣格原文的方法。
- `[E]` 社会心理学里的归因偏差、虚假共识等研究，可以部分对照「我们如何把自家问题放到别人身上」，但不能等同于荣格的阴影理论。

**本节只留一个问题**：我对这一点的反应，是在描述他/她，还是在描述我自己不允许有的部分？

## 8. 荣格 III：阿尼玛/阿尼姆斯与「理想型」

### 8.1 原著在说什么（意译概述）

荣格用「阿尼玛」指男性无意识中的女性面向，「阿尼姆斯」指女性无意识中的男性面向。它们不是「男人该怎样、女人该怎样」的规范，而是每个人心里关于「另一个性别」的内在图像。这个图像会参与择偶：你会对某些特质特别敏感，对另一些特质特别排斥。

**必须说明的时代局限**：荣格的性别二分是 20 世纪初的产物，带有本质主义色彩。今天更合适的读法是：**每个人心里都有一套「亲密关系模板」**，它不必按性别划分，也不必固定不变。

### 8.2 放进恋爱里

- 「理想型」不是错，错的是把模板当筛选器：只留符合模板的，筛掉的可能是真实适配。
- 「对的人总差一点」：差的可能不是对方，是模板本身太像想象。
- 模板可以谈。你可以说「我需要的是……」，而不是「你应该变成……」。

### 8.3 可验证练习：十条理想型，删到三条底线

1. 写下你对伴侣的十条期待。
2. 每条后面标：**观察过 / 想象 / 别人说的**。
3. 删掉「想象」和「别人说的」里无法观察的部分。
4. 只保留三条**底线**（不可协商），其余转为「偏好」。
5. 给每条底线配一个**可观察行为**。

示例：

| 期待 | 类型 | 可观察行为 | 底线还是偏好 |
|---|---|---|---|
| 情绪稳定 | 观察过 | 冲突时不摔东西、不消失、不羞辱 | 底线 |
| 有上进心 | 别人说的 | 每周有具体的学习/工作安排 | 偏好 |
| 和我有共同爱好 | 想象 | 每月至少一次共同活动 | 偏好 |

### 8.4 停止条件

- 你用类型标签（MBTI、星座、原型）判断「我们合不合」→ 停。类型不是关系证据。
- 你要求对方符合全部十条 → 停。这是找定制商品，不是找伴侣。
- 你把「没有火花」当作唯一淘汰标准 → 停。火花是起点，不是全部。

### 8.5 证据与边界

- `[T]` 阿尼玛/阿尼姆斯（荣格，《Two Essays on Analytical Psychology》，CW7）。**理论框架，非实证。**
- `[U]` 荣格的性别本质主义需要批判；现代关系研究不支持「男人来自火星、女人来自金星」式的二分。
- `[E]` 相似性、感知相似性与匹配假设对吸引有稳定影响（Byrne, 1971；Montoya 等，2008；Feingold, 1988）。
- `[C]`「十条 → 三类 → 三条底线」是本读本的练习设计，不宣称来自荣格。

**本节只留一个问题**：我的「理想型」里，有几条是能被我实际观察到的？

## 9. 荣格 IV：自性化——关系不是找另一半来完整你

### 9.1 原著在说什么（意译概述）

荣格用「自性化」描述一个人终生整合意识与无意识、逐渐成为更完整自己的过程。它不是变成完美的人，而是**能容纳自己的矛盾**：承认自己有攻击性、有依赖、有脆弱，也有能力。自性化不是离群索居，也不是拒绝关系；它恰恰要求一个人在关系里不把自己交给对方来定义。

### 9.2 放进恋爱里

「你让我完整」是一句很浪漫的话，但它藏着两个风险：

- **把伴侣当缺口填充物**：他/她一旦离开，你就碎掉。
- **用「成长」要求对方无限包容**：把边界问题说成「你不够爱我」。

更稳的方向是：**两个本来就不完美的人，带着各自的支点，选择一起生活。** 这不是「不依赖」，而是「依赖得具体、可协商、可撤回」。

### 9.3 可验证练习：五根自我支柱

| 支柱 | 不依赖伴侣的一个具体动作 | 本周做一次吗 |
|---|---|---|
| 身体 | 运动、睡眠、饮食 | |
| 工作/学习 | 一个可交付的小任务 | |
| 朋友 | 一次非恋爱话题的见面 | |
| 兴趣 | 一件只为自己做的事 | |
| 意义 | 一件让你觉得「这一天没白过」的事 | |

**自检问题**：如果伴侣这周不在，你的五根支柱里，有几根还能站住？

### 9.4 停止条件

- 你把伴侣当作唯一的情绪出口 → 停。这是把关系变成单点故障。
- 你用「灵魂伴侣」跳过现实协商（钱、家务、边界、性、家庭）→ 停。灵魂不需要协商，生活需要。
- 你以「我要成长」为名，要求对方无条件包容你的越界 → 停。成长不是免责。

### 9.5 证据与边界

- `[T]` 自性化与整合（荣格，《荣格自传：回忆·梦·思考》，1962；《分析心理学的理论与实践》，1935）。**分析心理学框架，非实证。**
- `[C]`「五根自我支柱」是本读本结合依恋与社会支持研究的综合练习。
- `[E]` 社会支持与关系满意、心理健康存在稳定关联；但支持不是越多越好，质量与边界同样重要。
- `[U]`「人必须完整才能爱」是流行说法，缺乏统一证据；更准确的说法是：自我越稳定，越不容易把关系变成救命绳。

**本节只留一个问题**：这段关系之外，我的哪一根支柱最近塌了？

## 10. 两位思想家的对照

| 问题 | 叔本华 | 荣格 | 本读本的用法 |
|---|---|---|---|
| 欲望是什么 | 匮乏产生的意志冲动 | 无意识图像的牵引 | 用机制解释，不用宿命解释 |
| 爱情是什么 | 物种意志借个体完成的幻觉 | 投射与内在图像的相遇 | 心动强度 ≠ 适配度 |
| 痛苦怎么办 | 看见普遍痛苦，以同情回应 | 看见阴影，整合而非压抑 | 共情 + 边界 |
| 自我往哪走 | 否定意志、审美静观 | 自性化、容纳矛盾 | 成长 ≠ 完美 |
| 他人是谁 | 同情的对象 | 投射的屏幕，也可以是具体的人 | 最终要把对方当具体的人 |
| 最大风险 | 悲观变成自我实现 | 理论变成标签与免责 | 两条红线都要防 |

### 他们一致的三点

1. **人不是完全理性的。** 欲望、无意识、身体与情绪，都在参与选择。
2. **关系不是满足自我的工具。** 把对方当工具，最终会反噬自己。
3. **看见自己，比看透对方更重要。**

### 他们分歧的三点

1. **叔本华倾向否定欲望，荣格倾向整合欲望。** 一个说「少要」，一个说「看清你要什么」。
2. **叔本华更悲观，荣格更强调成长与整合。** 一个说钟摆，一个说个体化。
3. **叔本华把「他人」看作同情的对象，荣格更强调撤回投射、看见具体的人。** 前者容易过度承担，后者容易过度解释。

## 11. 辅导流程：8 次课怎么上

### 11.1 每次的固定结构

| 环节 | 时长 | 辅导者做什么 | 学员做什么 |
|---|---|---|---|
| 开场 | 3 分钟 | 问上次动作的结果 | 说事实，不评价人格 |
| 复述 | 5 分钟 | 请学员用自己的话讲机制 | 讲「因为……所以……」 |
| 对照 | 5 分钟 | 请一个具体场景 | 说人、时间、原话 |
| 练习 | 5 分钟 | 给表格，不给答案 | 写一个动作 + 一个停止条件 |
| 自检 | 5 分钟 | 问「你怎么知道做到了」 | 自己回答 |
| 收尾 | 2 分钟 | 记录与预告 | 只记事实与下一步 |

### 11.2 八次课的主题与产出

| 次 | 主题 | 核心问题 | 产出 |
|---|---|---|---|
| 1 | 欲望的钟摆 | 我想要的是这个人，还是不再痛苦？ | 欲望三栏表 |
| 2 | 物种的计谋 | 除了心动，还有哪三条可观察的适配证据？ | 心动拆解表 |
| 3 | 同情与边界 | 我是在看见痛苦，还是在接管人生？ | 我能做/我不做 |
| 4 | 无聊与长期关系 | 我们最近一次共同经历是什么时候？ | 抗无聊清单 |
| 5 | 投射 | 我的判断里，哪一半有原话作证？ | 看到/补出/核对 |
| 6 | 阴影 | 我的反应在描述他/她，还是描述我自己？ | 三条受不了—我也有 |
| 7 | 理想型 | 我的理想型里，有几条能被观察到？ | 三条底线 |
| 8 | 自性化 | 这段关系之外，我哪根支柱塌了？ | 五根自我支柱 |

### 11.3 辅导者的四个「不」

1. **不替学员解释对方。** 「他/她一定是因为……」这句话不由辅导者说。
2. **不把哲学家当裁判。** 「叔本华说了……」不是证据，只是提问角度。
3. **不用理论贴标签。** 不说「你是回避型」「他是阴影投射」。
4. **不布置试探。** 不教查手机、故意冷淡、制造嫉妒、跟踪行程。

## 12. 十二个常见误用

| 说法 | 问题 | 改法 |
|---|---|---|
| 「叔本华说爱情是幻觉，所以别投入」 | 把悲观推断当规律，容易自我实现 | 「激情强度不是适配度；先看可观察证据」 |
| 「荣格说这是投射，所以你的感受是假的」 | 用理论否定真实感受 | 「哪些有原话？哪些是想象？」 |
| 「他/她是我阿尼玛的化身」 | 把内在图像当真人 | 「我补了什么故事？」 |
| 「你有阴影，所以你不该生气」 | 用理论堵嘴，转移责任 | 「先说具体行为，再谈反应」 |
| 「人要自性化，所以你不能依赖我」 | 用成长逃避互相依赖 | 「哪些支持是合理的？哪些越界？」 |
| 「我同情他/她，所以不能离开」 | 拯救者情结 | 「我能做的一件具体事是什么？」 |

| 「物种意志决定男人喜欢年轻女人」 | 用思辨为偏见背书 | 「这是群体统计，还是我的个人偏好？」 |

| 伪造原文、页码、逐字引文 | 破坏可信度，也无法核对 | 「意译 + 篇目；需要原文就查版本」 |

## 14. 一页速查

### 叔本华四句

- 欲望来自匮乏，满足是短暂的。
- 人生容易在痛苦与无聊之间摆动。
- 同情是看见痛苦，不是接管人生。
- 长期关系不能靠持续激情，要靠共同意义与日常结构。

### 荣格四句

- 心动 = 真实特质 + 内在图像 + 当下唤醒。
- 你最受不了的，可能是你不敢承认的自己。
- 理想型是模板，不是筛选器。
- 自性化是容纳矛盾，不是找另一半来完整你。

### 三条红线

1. **不用理论给伤害开脱。** 暴力、控制、撒谎、性胁迫，就是行为问题。
2. **不用理论预测对方。** 「他/她一定是……」不是证据。
3. **不用理论替代协商。** 钱、家务、边界、性、家庭，都要具体谈。

### 每次辅导只问三个问题

1. 我**观察到**什么？（原话、行动、持续回应）
2. 我**补出**了什么？（故事、动机、未来）
3. 下一步**可验证的动作**是什么？（7 天内能完成）
