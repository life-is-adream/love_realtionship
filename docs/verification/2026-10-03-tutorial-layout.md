# HeartFlow 教程站排版验证

日期：2026-10-03（Asia/Shanghai）。参考页面：https://www.runoob.com/ 。参考其顶部导航、左侧目录和分组学习内容，使用本项目自己的内容和界面。

## 实现

- 主页改为浅灰页面、白色正文、绿色导航；左侧210px目录、中央宽内容，不常驻右栏。
- 首页只显示六组课程与练习入口。对话、每日练习、连续约会、现实复盘、教练分析、成长、生活管理、角色设置各为独立视图。
- Hash导航支持前进、后退；未知视图回首页。切换仅控制可见性，不重建表单或清空草稿，不写入用户档案。
- 非当前面板同时使用hidden、inert和aria-hidden；手机目录折叠，选择后自动收起。
- 备份、恢复、重置、模式及模型检查移入设置；原功能控件ID保留，移除旧三项底部导航。
- 课程页采用同一浅色目录与正文结构，默认课程清单。知识地图与19份书籍仍可切换；支持view=list/map/books以及course=N直达。
- 长篇教材入口与关闭兼容新工作区，切章复位实际阅读滚动层。
- 没有修改课程原文、manifest、每日自动化、凭证或持久化格式；没有新增依赖，没有远程模型调用，没有提交或推送。

## 浏览器验证

- 1280px桌面：左目录与宽正文显示正常，无整页水平溢出；默认仅home可见。
- 在连续约会中输入合成草稿，切换现实复盘后返回：草稿保留，反馈可运行；测试草稿随后清空。
- 历史后退恢复对应功能，只有一个面板可见；聊天页展示当前角色和阶段，设置面板隐藏。
- 320px手机：默认目录收起，展开可以选择连续约会，选择后收起；页面scrollWidth=305，小于viewport=320，没有整页水平溢出。
- 桌面课程清单有179项；第179课直达仍自动打开原文。手机课程清单及第1课阅读均可用，无整页横向溢出。
- 长篇入口打开10章目录，隐藏工作区；关闭后恢复工作区。
- 各本地页面检查未发现控制台错误。未点击任何真实模型生成按钮，未测试外部模型质量。
- 最终将用户原有浏览器页留在新版首页；临时测试页面关闭，视口覆盖撤回。
