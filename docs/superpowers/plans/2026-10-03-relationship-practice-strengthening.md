# 恋爱实战训练加强 Implementation Plan

> **For agentic workers:** 本轮使用当前协作代理实现并由主代理集成验证；用户已授权执行，不另行等待计划审批。

**Goal:** 将现实卡点、正向相处练习、连续约会分支和现实结果复盘接入现有 HeartFlow，并同步179课学习入口。

**Architecture:** 新增独立的纯函数训练模块和渲染器，由现有 app.js 装配。现实复盘默认只在本页保存，明确选择后仅持久化枚举摘要；模拟与现实结果分别展示。

**Tech Stack:** Node.js ESM、原生浏览器 JavaScript、node:test；不增加依赖。

## Global Constraints

- 保留已有 dirty 文件的内容；不提交代码，不执行破坏性操作。
- 不改写179份每日课源文件，不调整每日自动化，不调用远程模型。
- 不读取私人聊天、profile、认证或凭证。
- 练习分数不解释为喜欢概率、心理诊断或现实效果。
- 时间统一使用 Asia/Shanghai；拒绝和不合适允许停止。

- [x] 现实复盘：新增 `real-practice.js` / `render-real-practice.js`；规范化枚举记录、默认关闭持久化、撤回后清除、明确拒绝停止、未知保持未知。
- [x] 产品集成：修改 `app.js`、`index.html`、`render-learning.js`、`core/state.js`、`styles.css`，按手选卡点安排微训练并挂载新面板。
- [x] 课程同步：构建脚本支持 `--courses-only`，生成179课可读取资产并保留全部 books 元数据。
- [x] 验证：新增模块测试、状态持久化测试；运行相关测试、完整 `npm test` 和 `npm run check:circular`；在隔离本地端口验证界面交互。

## Acceptance

六种卡点各有准备练习、现实行动、观察点与停止条件；连续模拟不会把模糊或拒绝自动升级；未知结果不产生成功判断；刷新前后的记录行为符合保存开关；179课编号、文件与来源一致。通过本地工程验证只报告功能完成，不宣称真实恋爱效果已得到证明。
