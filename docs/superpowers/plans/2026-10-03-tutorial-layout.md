# HeartFlow 教程站排版 Implementation Plan

> **For agentic workers:** 使用当前协作代理分工实现；用户已授权修改排版，不另行等待设计审批。不提交代码。

**Goal:** 参考菜鸟教程的目录与正文结构，降低主页密度，让用户一次处理一个学习或练习任务。

**Architecture:** 保留原业务模块和DOM ID，将界面分成由左侧目录切换的独立视图。主页成为学习目录；新浅色样式覆盖既有组件。课程阅读页同步视觉并默认课程清单。

**Tech Stack:** 原生HTML/CSS/JavaScript、Node.js node:test；不增加依赖。

## Constraints

- 保留现有修改、已保存数据、179课源文件及每日自动化；不读取私人聊天或凭证。
- 仅修改界面组织、导航及必要事件集成；不调用远程模型。
- 桌面是左侧目录与宽正文；移动端折叠目录，不常驻右侧提示栏。
- 所有功能仍可访问，切换视图不销毁输入和模拟进度；隐藏面板不可键盘访问。
- 沿用确认、保存及安全边界；不因排版新增清除或覆盖动作。
