# 教练评分校准基准说明

> 版本：v1.0 | 撰写：工程师寇豆码 | 基于增量 PRD P0-5 和设计文档 T03

---

## 一、校准前后基准分对比表

| 维度 | 校准前基准分 | 校准后基准分 | 变化 | 理由 |
|------|------------|------------|------|------|
| **自然度 (naturalness)** | 56 | 54 | -2 | 减少基础鼓励分，让"无具体内容的长句"不再自动获得虚高分数 |
| **共情 (empathy)** | 54 | 54 | 不变 | 基准分保持，但 hasEmpathy 加分从 18 降至 14 |
| **边界感 (boundary)** | 78 | 70 | -8 | 修复"无越界词即高分"的虚高问题，78 分基线让正常回复也显得过于安全 |
| **推进力 (momentum)** | 52 | 52 | 不变 | 基准分保持，但 hasQuestion 加分从 18 降至 15 |

## 二、权重调整明细

| 信号 | 校准前 | 校准后 | 影响维度 | 说明 |
|------|--------|--------|---------|------|
| `hasEmpathy` 加分 | +18 | +14 | empathy | 减少关键词命中即高分的倾向 |
| `hasQuestion` 加分 | +18 | +15 | momentum | 降低问题命中带来的推进力虚高 |
| `hasOverthinking` 扣分 | 无 | -8 (naturalness) / -6 (boundary) | naturalness, boundary | 新增：检测过度解释（"我意思是""不是说你"等连用） |
| `hasSpecificReference` 加分 | 无 | +6 (empathy) / +5 (momentum) | empathy, momentum | 新增：引用对方具体原话而非泛化表达 |

## 三、各维度调整理由

### 3.1 自然度：56 → 54
原基准分 56 意味着即使只发一个中长句（无具体内容、无问题），自然度也能达到 60+。调整后，需要更多具体信号才能达到 70+，更真实地反映回复质量。

### 3.2 边界感：78 → 70
这是本次校准最重要的调整。原基准分 78 导致"只要没有越界词就接近 80 分"，无法区分"安全的普通回复"和"真正有分寸的高质量回复"。调整后，无越界词的普通回复在 70 分左右，需要主动展现边界意识（如自我修正、给对方选择权）才能达到 75+。

### 3.3 共情：基准不变，加分降低
基准分 54 保持不变，但 `hasEmpathy` 加分从 18 降至 14。原设定下，命中一个共情关键词（如"辛苦""谢谢"）就能让共情分跳到 72+，过于宽松。调整后需要更多信号叠加才能达到高分。

### 3.4 推进力：基准不变，加分降低
基准分 52 保持不变，但 `hasQuestion` 加分从 18 降至 15。原设定下，任何包含问号的回复都能获得 70+ 推进力，无法区分"好的开放问题"和"模板化追问"。

## 四、新增信号说明

### 4.1 hasOverthinking（过度解释检测）
- **检测模式**：`/我意思是|不是说你|其实我就是|就是说|我的意思是|不是那个意思|我不是说/` 连续出现 ≥2 次
- **扣分**：naturalness -8, boundary -6
- **理由**：过度解释通常意味着不安全感或试图控制对方理解，既不自然也有轻微施压感

### 4.2 hasSpecificReference（具体引用检测）
- **检测模式**：`/你刚才说的|你提到的/` 或包含引号引用
- **加分**：empathy +6, momentum +5
- **理由**：引用对方具体原话表明在认真倾听，比泛化"你说的"更有连接力

## 六、用户历史日志解读指引

### 校准前后分数不可直接比较

本次校准改变了各维度的基准分和权重，因此：
- **校准前**的历史训练日志中的分数（无 `baseline` 字段或 `baseline` 非 `"calibrated"`）是按旧基准生成的
- **校准后**的新训练日志中的分数（`baseline: "calibrated"`）是按新基准生成的

### UI 标注

历史日志条目如果缺少 `baseline: "calibrated"` 字段，会在 UI 旁显示"校准前"小标签，提醒用户不要直接与校准后的分数比较趋势。

### 建议解读方式

- 校准前的 boundary 分数普遍偏高（78 基准），不要因为"以前 80 分现在 72 分"认为退步
- 关注校准后的分数趋势，而非与旧数据横向比较
- 如果需要重新评估历史练习的质量，可以在校准后的基准下重新发送相同回复查看新分数

### 基准阈值说明

正向样本并非全部使用同一个 75 分下限。对“具体自然、明确自我修正、接受拒绝”等强信号样本使用 ≥75；对“留出口、事实型共情、具体比喻”等单一或较弱信号样本使用 ≥60/65/70。后者是对启发式评分能力边界的明确记录，不代表这些表达的关系价值低于强信号样本。

## 七、实际启用的新增信号清单

除 `hasOverthinking` 与 `hasSpecificReference` 外，校准后的 `coach.js` 还启用了以下组合信号；它们只影响本地评分和反馈，不改变 `buildCoachScore` 的函数签名：

| 信号 | 主要作用 |
|---|---|
| `hasVagueImplication` | 降低模糊暗示、把解释责任推给对方的边界感 |
| `hasPatronizing` | 降低居高临下评价式表达的共情 |
| `hasSelfCorrection` | 提高承认并收回不当表达的边界感 |
| `hasAcceptance` | 提高接受拒绝或调整方案的边界感 |
| `hasBoundaryRespect` | 提高给选择权、留空间的共情与边界感 |
| `hasEmpatheticStatement` | 提高明确表达理解的共情 |
| `hasOpenDoor` | 提高给未来回复留下接口的推进力 |
| `hasCreativeMetaphor` | 提高具体、生动表达的自然度 |
| `hasEmotionalCheck` | 降低检查式追问的边界感 |
| `hasDismissive` | 降低轻描淡写或否认感受的边界感 |
