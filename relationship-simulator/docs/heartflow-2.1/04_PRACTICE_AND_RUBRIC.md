# S4 场景合同、状态校验与五维评分 v2.1.0

## 1. 场景合同

文件：`quality/scenarios/contracts-2.1.json`（`scenario-contract-2.1.0`）。

每个场景包含：`id/version/title/relationship_context/difficulty_range/branches/allowed_state/boundaries/termination_rules/learning_objectives/dimensions`。

终止规则：

- `breakup-recovery`：首轮即结束；任何复合请求不重新打开互动。
- `low-pressure-invitation` / `low-energy-reply` / `conflict-repair`：`declined` 分支首轮结束；连续施压 tension 达到 3 结束。
- 对方明确拒绝或要求暂停：结束，不因后续道歉恢复推进。

状态由服务器从 `history + response` 重建，**不读取客户端 `state`**；伪造 `{tension:100, repair:-1}` 不影响输出。`tension/repair` 均为 0–3 整数，越界由重建逻辑夹紧。

## 2. 行为修复

| 问题 | 修复 |
| --- | --- |
| “我不想证明什么”被当作施压 | 压力词也走同分句否定窗口，`不/没/别` 后的“证明”不计 |
| “对不起，但你必须原谅我”被道歉抵消 | 同句道歉+施压时安全优先，先按施压计 |
| “我不会放弃”未识别为施压 | 增加 `不会放弃` |
| “我去找你”“都是你的错”未识别 | 增加 `去找你`、`都是你的错` |
| 客户端伪造 state | 服务器重建，忽略输入 |

## 3. 五维评分 v2.1.0

维度：倾听、清晰度、边界、自然度、冲突处理。每维 0–4 分；`maximum = 可评分维度 × 4`。

### 3.1 行为锚点

| 分数 | 倾听 | 清晰度 | 边界 | 自然度 | 冲突处理 |
| --- | --- | --- | --- | --- | --- |
| 0 | 完全无视对方说过的内容 | 意图无法理解或自相矛盾 | 施压、威胁、逼迫原谅 | 机械、重复、明显模板化 | 指责、羞辱、升级冲突 |
| 1 | 只回应自己，未承接对方 | 含糊，需大量猜测 | 忽略拒绝或暗示继续 | 生硬但可读 | 回避或转移责任 |
| 2 | 复述一个对方事实，但未回应感受 | 有一个具体请求/信息 | 不施压，但未明确保留拒绝空间 | 基本通顺，略有套话 | 能停下指责，但未提出协商 |
| 3 | 复述事实并回应感受/需求 | 具体、可执行、可拒绝 | 明确接受拒绝/暂停 | 自然、口语化、不堆砌术语 | 区分事实/感受，提出一个协商点 |
| 4 | 准确抓住核心矛盾并给出对方可校正的理解 | 简洁、具体，给对方选择且不越界 | 主动确认边界并提供退出路径 | 像真实对话，语气与关系阶段匹配 | 能命名分歧、共同定义下一步，允许暂停 |

### 3.2 证据规则

- 每个维度证据必须是具体 turn 的**完整句子**，带 `message_id/quote`；完整句子是必要非充分条件。
- 只评价可见文字，不推断人格、动机、依恋类型或现实行为。
- 无法观察的维度标 `not_applicable`（`applicable=false`），不强制 0 分。
- 证据不足标 `insufficient_evidence`，不把“没有证据”当作低分。
- 规则评分只用于产品反馈，不得对外宣称心理测量效度。

### 3.3 人工盲评协议（未执行）

1. 至少 2 名独立评委；随机打乱模型/版本来源，隐藏分组。
2. 样本量：每维度至少 60 条有效评分；正式发布建议 120 条以上并预注册指标。
3. 评委先读锚点并完成 5 条校准样本；分歧 >1 分时仲裁。
4. 报告：逐维均值/中位数、95% CI、ICC(2,k) 或 Krippendorff alpha、与自动评分的一致性（Spearman）、失败案例。
5. 自然度必须单独盲评，不能用规则分代替。

**当前状态：`BLOCKED_EXTERNAL_VALIDATION`。** 未进行真实用户测试、未招募独立评委、未计算 ICC/alpha；自动评分只完成合同测试。
