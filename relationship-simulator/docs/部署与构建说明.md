# HeartFlow 部署与构建说明

## 启动

在 `relationship-simulator` 目录执行：

```powershell
npm install
npm run build:index
npm start
```

浏览器访问 `http://localhost:3000`。

## 目录职责

- `public/app.js` 只负责依赖装配、事件绑定和跨模块流程编排。
- `public/modules/core/state.js` 是浏览器状态唯一来源；`public/modules/coach/parser.js` 保留模型输出和离线兜底解析。
- `public/modules/core/api-client.js` 是模型网络边界；渲染模块不直接拼接主聊天请求。
- `server/index.js` 负责 HTTP 路由装配；`.env`、静态文件、长篇内容、健康检查和模型代理分别位于 `server/` 子模块。

## 修改长篇教材

修改 `long-simulation/` 下的 Markdown 后重新生成前端索引：

```powershell
npm run build:index
```

不要手动编辑 `public/modules/content/long-content-manifest.js` 与 `public/modules/content/long-content/chapter-XX.js`（按章拆分产物，消费方统一走 `long-content-loader.js`）。

## 验证

```powershell
npm run check:circular
npm test
```

模型未配置时，主聊天仍会使用本地兜底；教材阅读、本地分析、回放和训练功能不依赖模型密钥。
