# 风险与后续工作

## 当前最重要的限制

1. **多用户与归属未完成。** 新档案保存在同一浏览器本地，v2 分析/训练没有服务端持久资源，服务端也没有用户身份、会话归属或跨用户访问控制。对于任务书要求的服务端强制授权和跨用户隔离，目前只能在不写服务端记忆的范围内规避自动写入，不能视为完成多用户安全要求。
2. **局域网/公网暴露已收敛，但不能当成加固服务。** C 与 Node 现在默认只监听 `127.0.0.1`，`/api/*` 均校验页面来源；只有显式设置 `HF_BIND_HOST`（或 `--bind`）才监听其他地址，此时私有网段来源会被放行，且仍没有 TLS、账户或速率以外的基础设施防护。不要将当前服务直接暴露到公网或不受信任的局域网。
3. **真实模型和语音尚未验收。** 截图需要支持视觉输入的模型及有效配置；模型角色、回复、独立复核有错误和编造可能。语音输入可能由浏览器供应商处理，停顿仅是粗略音量阈值。
4. **规则、建议与评分尚未专业校准。** 关键词不能充分理解否定、上下文或人的处境；单个证据词不一定足以证明所有评分理由。课程按标题/目标匹配，不是经验证的语义或全文检索。
5. **数据生命周期有边界。** 新分析不自动存入关系档案，但原有聊天和训练记录可以保存在浏览器。已导出文件、旧备份、浏览器缓存及远端提供商保留的数据不随档案授权撤销自动删除。删除前应确认这些副本。
6. **取消不是远端撤回。** 浏览器停止等待并拒收迟到结果，但请求可能已进入 C 服务或模型供应商；对方已看到的双人分享内容也无法撤回。

## 不作的推断

当前实现和合成测试不证明关系建议有效、提高用户沟通能力，或达到任务书提出的任何人工质量门槛。真实用户研究及其必要授权、样本和独立评审仍是尚未完成的外部验证工作。
