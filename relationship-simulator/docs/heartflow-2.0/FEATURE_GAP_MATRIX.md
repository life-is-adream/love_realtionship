## 不推荐直接照搬

不提供对方心理或兴趣的确定性判定、无依据好感率/成功率、偷拍或绕过对方意愿、自动发送、压迫式追求、把模型模拟分数包装成现实效果。相关建议应保留证据、未知和自主选择。
