# HeartFlow 项目功能与技术栈

HeartFlow 是一个本地运行的恋爱成长与关系沟通训练系统。它将课程学习、聊天分析、情境模拟、反馈和复盘连接起来，帮助用户理解沟通中的信息、练习表达并自主决定下一步。

## 主要功能

1. **关系问题分析**：导入聊天文字、事件叙述或聊天截图，人工修正后查看原文依据、可能解释、未知信息和行动建议。
2. **回复建议**：无需展开完整报告即可获得自然、温和、清晰边界三种表达；也可在同意发送内容后使用模型生成更多建议。
3. **情境模拟与反馈**：选择虚构场景、难度和回应分支，进行多轮练习；系统从倾听、表达、边界等维度展示规则反馈和原文依据。
4. **课程学习与每周计划**：从本地 179 节课程中匹配相关内容，并根据自主选择或练习反馈生成每周小任务。
5. **关系档案与成长记录**：为不同关系分别建立档案，经用户授权后手动保存事件、推测、结果、摘要或练习规则分数；可查看同一情境和维度的趋势，支持撤销、删除与导出。
6. **双人互动**：双方在同一设备上独立填写问题答案，各自同意后才在页面显示。
7. **语音能力**：可复用现有语音合成服务朗读情境和反馈；支持浏览器语音输入和粗略停顿统计，具体能力取决于浏览器和服务配置。

## 技术栈

| 层次 | 技术 |
| --- | --- |
| 前端 | HTML、CSS、JavaScript ES Modules；浏览器本地存储和 Web Crypto |
| 主服务 | C 语言 HTTP 服务，提供本地分析、课程匹配、训练评分和模型代理 |
| 参考服务 | Node.js，保留对应接口用于行为对照 |
| 模型接入 | 兼容 Chat Completions / Responses 风格的模型接口；截图识别需要支持图像输入的模型 |
| 语音 | Python TTS sidecar 与 C 语音代理；浏览器语音识别 API |
| 数据与内容 | 本地课程 Markdown 和 JSON 索引；浏览器本地保存用户主动授权的档案与计划 |
| 测试 | Node.js 测试、Python 接口回归、Chrome/Edge 浏览器端到端测试 |

## 使用边界

系统区分用户提供的原文、推测与未知；模型建议和启发式分数需人工判断，不代表对方的真实心理或现实关系结果。新增关系档案默认不保存复盘；截图和可选模型功能会在用户同意后向配置的服务发送相应内容。服务默认只监听本机 `127.0.0.1`，需显式设置 `HF_BIND_HOST` 才开放局域网；当前档案是单浏览器本地功能，尚不是多用户账户系统。
